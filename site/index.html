Bring your i3 config

Panespace reads i3's syntax, so your bindings, modes and window rules come along. Starting fresh? It writes a commented default on first run.

  • check-config flags any line it can't use
  • Bindings follow your keyboard layout
  • Reload after an edit with $modShiftC

Any window, two keystrokes away

The switcher searches every window by app, title or workspace. Window hints put a letter on everything you can see. Type it and you're there.

  • Fuzzy search, so ter finds Terminal
  • Minimized and full-screen windows show up too
  • hints swap trades places with the window you pick

Workspaces without the wait

Panespace keeps its own workspaces instead of macOS Spaces. Switching moves each window once, with no animation to sit through. Swipe with four fingers and they follow, then snap.

  • Move windows and whole workspaces between displays
  • Workspaces return to their display when you plug it back in
  • Immersive mode hides the menu bar with one key

Script it like i3

panespace msg speaks the same commands as i3-msg, so your scripts, status bars and launchers can drive it.

How it works

Accessibility API only
No SIP changes and no scripting additions.
One background queue per app
A frozen app can't hold up your keys.
Spring animation in step with the display
Windows settle without overshoot.
A tested core
The layout tree and config parser are a plain Swift module with unit tests.

The keys you already know

$mod is ControlOption out of the box. Switch it to Caps Lock, Option, Command or Hyper from the menu bar.

Focus left, down, up, right
$modHJKL
Move the window
$modShiftHJKL
Switch workspace
$mod1to0
Send the window to a workspace
$modShift1to0
Split horizontally or vertically
$modBorV
Tabbed, stacking, toggle split
$modW/S/E
Full screen
$modF
Float or tile the window
$modShiftSpace
Window hints
$mod;
Search all windows
$mod/
Resize mode
$modR
Close the window
$modShiftQ
